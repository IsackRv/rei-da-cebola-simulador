
# Rei da Cebola - Simulador de Compras

## Informações do projeto
Aluno: Isack Damacena Sousa

Trilha: Desenvolvimento Mobile

Desafio 1: Minha Loja - Simulador de Compras

## Sobre a loja
O Rei da Cebola é uma loja de hortifruti que
oferece frutas e verduras com qualidade e
preços acessíveis.

## Produtos
- Tomate: R$ 4,99/kg
- Cebola: R$ 5,49/kg
- Laranja: R$ 4,99/kg

## Tecnologias utilizadas
- HTML: estrutura da página.
- CSS: aparência verde e branca.
- JavaScript: simulação das compras.

## Como executar
1. Baixe os arquivos do projeto.
2. Abra o arquivo index.html no navegador.
3. Clique em "Simular compra".
4. Informe as quantidades desejadas.
5. Confira o resultado da compra.

## Testes realizados
- Compra com três produtos: aprovado.
- Cálculo do total de R$ 30,44: aprovado.
- Compra com todas as quantidades zero: aprovado.
